安装

两行命令,即刻上手。

1

运行安装脚本

一键下载并安装到 ~/.claude/statusline/,自动写入 settings.json。

curl -fsSL https://raw.githubusercontent.com/ember-hearted/statusline/master/bin/install.sh | bash
2

重载插件

在 Claude Code 中运行以下命令,状态栏即刻生效。

/reload-plugins
